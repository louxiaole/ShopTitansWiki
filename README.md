# 小乐的商店百科

**Shop Titans 攻略百科** —— 一站式《商店泰坦》游戏数据查询与装备模拟桌面工具。

无需联网依赖，便携版绿色运行。所有数据取自最新版游戏解包，中文名采用官方本地化译名，随游戏版本持续更新。

## 功能特性

- **装备图纸 1700+**：全部图纸分类筛选、详情查看，制作所需资源与组件需求一目了然
- **勇士模拟器（15 名勇士）**：等级属性模拟、评级（Rank）体系、光环与随从搭配、战力实时计算
- **英雄职业**：职业、属性、成长数值全览
- **技能 500+**：全部技能效果与加成查询（含闪避/暴击/破甲/战利品等特殊效果）
- **元素 / 精萃与材料**：元素克制关系、精萃与材料全览
- **冒险模拟**：队伍战力预估，助你挑选最强阵容
- **活动冒险**：活动冒险数据速查
- **官方译名**：所有物品/技能中文名均采用游戏官方本地化译名，准确无偏差
- **便携版桌面应用**：单 exe 免安装，双击即用

## 下载安装

**方式一：直接下载**

1. 前往 [Releases](https://github.com/louxiaole/ShopTitansWiki/releases) 页面
2. 下载最新版本 `小乐商店百科-1.0.0.exe`
3. 双击运行，无需安装，绿色便携

**方式二：工具内自动更新**

已安装旧版本的用户，打开工具后会自动检测新版本，点击「立即更新」即可在线更新。

## 使用说明

1. 双击 exe 启动，进入工具主界面
2. 顶部导航切换「装备图纸 / 英雄 / 勇士 / 技能 / 元素精萃与材料 / 冒险模拟 / 活动冒险 / 赞助」
3. 在「装备图纸」页按分类筛选蓝图，点击查看详情（制作资源与组件需求）
4. 在「勇士」页选择勇士，拖动等级与评级滑块，搭配光环与随从，实时查看战力
5. 数据随游戏版本更新，请保持工具为最新版本
